# Hypertrophy Coaching Dashboard

A self-contained, responsive HTML dashboard for an Upper/Lower hypertrophy and body-recomposition plan.

## Open it

Open `outputs/index.html` in a modern browser. It has no external dependencies.

## Included files

- `outputs/index.html` — the interactive coaching dashboard
- `outputs/hypertrophy-dashboard-generator-prompt.md` — the reusable HTML-generator prompt
- `outputs/hypertrophy-coaching-context.md` — the coaching-plan source of truth

The weekly review fields use browser-local storage only; no data is transmitted or stored by this project.
